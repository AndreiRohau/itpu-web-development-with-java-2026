## Rules

COURSE RULES on how to get 100 merit-points:
1. I have 100 merit-points to share with each of you during semester.
2. We have 29 workshops.
3. During each workshop you can get 3 merit-points in accordance with the quiz results (quiz occures during each workshop).
4. Every quiz would contain 10 questions which in a success run may bring you from 5000 to 10 000 menti-points (depends on how fast you answer questions).
5. Quiz results would be converted to merit-points according to the following rules:
```
    MENTI-points range == MERIT-points equivalent

   [3333, 10000] == 3
   
   [2222, 3332] == 2

   [1111, 2221] == 1
   
   [0, 1110] == 0
   ```

6. So after all quiz sessions MAX merits amount would be 90.

7. The remaining 10 points will be given at my personal discretion.
